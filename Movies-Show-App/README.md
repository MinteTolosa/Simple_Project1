# Movies-Show-App

A simple web app for discovering TV shows and saving favorite shows. It has a Netflix-inspired dark design and works on both desktop and mobile.

## Features

* Search for TV shows
* View popular shows
* Save favorite shows
* Remove favorite shows
* Responsive design
* Save favorites using Local Storage

## Built With

* HTML
* CSS
* JavaScript
* TV Show API
* Local Storage

## How to Run

1. Download or clone the project.
2. Open the `Movies-Show-App` folder in VS Code.
3. Open `index.html` in your browser.
4. Search for a show and save your favorites.
