# My Portfolio Website

This is my personal portfolio website. I built it to practice my HTML and CSS skills and to showcase my skills and projects.

## 🛠️ Built With

* HTML5
* CSS3
* Flexbox
* CSS Grid
* Font Awesome
* Google Fonts

## 📌 Sections

* Home
* About Me
* Skills
* Projects
* Contact

## 📱 Responsive Design

The website works on:

* **Mobile:** 1-column layout
* **Tablet:** 2-column project layout
* **PC:** 3-column project layout

## 🚀 How to Run

1. Open the project in VS Code.
2. Open `HTML/index.html`.
3. Run it with Live Server or open it in your browser.
